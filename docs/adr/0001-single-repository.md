# ADR-0001: 単一リポジトリへの統合

日付: 2026-08-04
状態: 採択

## 背景

Claude Code / Codex の起動・設定資産が OS 別・ツール別の複数リポジトリに分散し、重複管理・更新漏れ・基準不統一が発生していた。

## 決定

本リポジトリ `AI-Coding-Startup-Tools` を正本とし、7 つの統合元リポジトリの資産を段階的に統合する。

## 結果

### 良い点

- 設定・ポリシー・テンプレートの一元管理
- CI による継続検証が可能
- 利用者の導入手順が単純化

### 悪い点・リスク

- 統合時に新旧ファイルを取り違えるリスク → ハッシュ・更新履歴・動作試験で比較
- 統合元の早期削除リスク → 段階移行とアーカイブで対応

## 代替案

- 複数リポジトリ維持 + ドキュメント集約: 重複管理コストが残るため不採用
- モノレポ分割（パッケージ分割）: 初期リリースでは過剰なため不採用
