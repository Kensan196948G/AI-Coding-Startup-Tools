## 1. 評価の結論

**総合判定: 条件付き利用可**（IT/DX 部門の開発インフラとして本番利用可能な水準に到達）

- 改善前（v0.3.1）総合 75.2/100 → **改善後（v0.4.0）82.4/100**（+7.2）
- 競合代替率 59% → **81%**（主要業務フロー 85%・必須機能 88%・セキュリティ/監査 85%）
- 重大リスク 5 件（認証 fail-open / Codex YOLO 自動付与 / symlink バイパス / E2E skip / CSP・localStorage）は**すべて解消済み**
- 本番導入の条件: `AI_WEBUI_TOKEN` の確実な設定・`AI_WEBUI_ALLOW_DANGEROUS=0` 維持・**検証環境での実地スモーク完了（2026-08-12 実施済み）**・PR マージ後の CI（Windows）確認済み

## 5. 強み・弱み・リスク

### 強み（15 件）

1. 重大セキュリティ問題 5 件を解消（fail-closed / YOLO 制御 / symlink / E2E / CSP・トークン保存）
2. 監査ログ: JSONL + 日次ローテーション + gzip + 秘密値マスキング + 7 世代保持
3. 5 系統 CI（Node / ShellCheck / Bats / PSScriptAnalyzer / Pester / security）
4. 依存ゼロの WebUI（Node 標準モジュールのみ）+ xterm.js 同梱 PTY 中継
5. dry-run 既定・バックアップ・ロールバックの安全設計
6. Windows / Linux クロスプラットフォーム対応（SSH + PowerShell）
7. systemd hardening（NoNewPrivileges / ProtectSystem=strict / PrivateTmp / RestrictAddressFamilies）
8. 日本語完全文書化（要件・設計・ADR・Runbook・導入ガイド・評価書）
9. バージョン単一正本化（package.json 起点、lockfile 含めて整合）
10. 障害通知（systemd OnFailure → Webhook、設定時のみ）
11. プロンプト・設定・移行台帳・秘密情報の自動検証（`npm run validate`）
12. タイミングセーフ比較・IP 単位レート制限・同時接続上限・24h セッション期限
13. スタブ + 実 CLI 併用の E2E スモークで CI の skip 問題を解消
14. 競合分析（5 製品、一次情報、更新日明記）で代替率 81% を算定
15. MIT ライセンス・SECURITY.md・CONTRIBUTING.md・CODEOWNERS・PR テンプレート完備

### 弱み・リスク（15 件、影響度付き）

| # | 項目 | 影響度 | 説明・対応 |
|---|---|---|---|

## 8. AI 設計方針（チャット目的化しない）

本ツールは AI 機能自体を提供しない。以下の原則で AI 活用を追加する場合も、**時間削減・検索/判断支援・説明可能性・安全性・費用対効果**で評価し、不要な領域はルール・検索で代替する。

| 領域 | 手段 | 根拠・引用 | 人間承認 | 権限 | 費用管理 |
|---|---|---|---|---|---|
| プロンプト・テンプレート検索 | RAG（社内文書を一次情報化、出典 URL/パス + 更新日付を引用） | 必須（引用なしは回答不可） | 生成物の利用は利用者判断、重要操作は承認 | 閲覧権限で検索範囲を制御 | トークン上限・月次予算 |
| 監査レポート要約 | 構造化抽出 + LLM 要約（元 JSONL を保持） | 要約は原文行番号へリンク | レポート確定は管理者承認 | 管理者のみ | バッチ上限 |
| 利用量予測 | ルール + 統計回帰を基本とし、LLM は補助 | 予測モデル指標を開示 | 予算アラート発火はルール | 管理者 | — |
| 異常検知 | ルール（閾値）+ 必要時 LLM で状況説明 | 検知根拠の指標値を明示 | 障害対応は運用手順に従う | 管理者 | 低コスト優先 |
| チャット（自由会話） | 導入しない（エージェント本体が担当） | — | — | — | — |

必須の安全対策:

- プロンプトインジェクション対策（外部入力の隔離・命令とデータの分離・出力の検証）
- 個人・機密情報保護（PII 検出、ログ非保持、暗号化、保持期限）
- モデル・プロンプト・入出力の監査（実行者・時刻・モデル・要約、内容は同意後）
- 誤判定時の責任分界（AI 出力は提案であり、最終判断は人間。利用規約・ポリシーを明記）
- 停止手段（緊急停止フラグ、予算上限到達時の自動停止、RBAC による強制停止）
