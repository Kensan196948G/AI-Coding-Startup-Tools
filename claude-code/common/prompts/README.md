# Claude Code 固有プロンプト

ツール固有プロンプトは `prompts/claude-code/` に配置します。ここには配置先の案内と補足を記載します。

- 共通プロンプト: `prompts/common/`
- Claude Code 固有: `prompts/claude-code/`
- 例: `prompts/examples/`

プロンプトのメタデータ仕様は [詳細設計仕様書 6. プロンプト設計](../..//AI-Coding-Startup-Tools_詳細設計仕様書.md) および `common/schemas/prompt.schema.json` を参照してください。
