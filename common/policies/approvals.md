# 承認ポリシー

## 承認が必要な操作

| 操作 | 既定 | `--yes` での省略 |
|---|---|---|
| 既存ファイルの上書き | 承認必要 | バックアップ + 個別確認必須 |
| パッケージ導入 | 承認必要 | 許可 |
| 権限昇格 | 承認必要 | 不可 |
| 外部への書込み・送信 | 承認必要 | 不可 |
| main へのマージ | 承認必要 | 不可 |
| 本番デプロイ | 承認必要 | 不可 |
| 再帰削除 | 承認必要 | 不可 |
| Secrets 変更 | 承認必要 | 不可 |
| 課金操作 | 承認必要 | 不可 |

## 非対話環境

対話端末でない環境で承認が必要な操作に到達した場合は、終了コード 4 で停止し、必要なコマンドを表示する。
