# 安全ポリシー

## 目的

本リポジトリが提供するスクリプト・プロンプト・テンプレートを安全に利用するための共通ルールを定める。

## 基本原則

1. 既定動作は読取り・診断・プレビューとする。
2. ファイル変更、パッケージ導入、外部通信、権限昇格は明示的なオプションと確認を必要とする。
3. 変更前バックアップ、原子的更新、冪等性、ロールバックを必須とする。
4. 高リスク操作（main マージ、本番デプロイ、外部送信、再帰削除、Secrets 変更、課金操作）は、`--yes` を指定しても自動承認しない。
5. 秘密情報を引数・設定ファイル・ログ・Git へ残さない。

## 禁止実装

- `curl ... | sh` / `wget ... | bash`
- `Invoke-Expression` による取得コード実行
- API キーを CLI 引数に含める実装
- TLS 検証の無効化
- 未検証の再帰削除、ワイルドカード削除
- ルート、ホーム全体、ワークスペース全体を再帰対象に指定する処理

## プロンプトの安全境界

- 自律実行プロンプトには承認ゲートを含める。
- 停止条件（本番反映、main マージ、削除、課金操作）に達したら作業を中断し、利用者の承認を待つ。
- プロンプト本文を Shell の `eval` や PowerShell の `Invoke-Expression` へ渡さない。
