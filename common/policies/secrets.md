# 秘密情報ポリシー

## 保管禁止

以下の情報を Git リポジトリ、ログ、CLI 引数、設定ファイルへ保存・出力してはならない。

- API キー、アクセストークン（GitHub、OpenAI 等）
- Cookie、セッション情報
- 秘密鍵、証明書の秘密部分
- 実値入り `.env`
- 個人情報、会社業務データ

## 承認済み保管先

- OS 資格情報ストア
- 環境変数（許可されたもののみ）
- GitHub Secrets
- パスワードマネージャー

## 設定ファイルの扱い

設定ファイルには秘密値の実値を書かず、参照名（環境変数名等）だけを保持する。

## 検出と対応

- `.gitignore` で典型的な秘密ファイルを除外する。
- pre-commit フックと CI の secret scanning を利用する。
- 誤ってコミットした場合は、履歴浄化（例: `git filter-repo`）をメンテナー承認の上で実施し、トークンは失効・再発行する。
